# Proof of Notik's Singer-ruler conjecture with sparse certificates

**Authors:** Haobo Ma, Wenlin Zhang

We prove Notik's conjecture in Section 7, page 7 of Golomb rulers with real marks (Zenodo version 2, 31 October 2026, DOI 10.5281/zenodo.23844781; arXiv:2611.22656v1): for every prime power, every Singer ruler is the unique shortest point of its real, unit-separated distance-order chamber. More generally, cutting any cyclic perfect difference set at its unique largest gap gives this property. Every positive integer smaller than the removed gap occurs as an ordinary distance; the chamber inequalities therefore bound each retained adjacent gap below by its integer value. We give a positive integer dual certificate supported on exactly one row per retained gap; its matrix is unit triangular. The same argument gives sharp stability bounds. Explicit largest-gap examples answer Notik's analogous Bose and Ruzsa questions negatively.
